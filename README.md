# 漫画收藏增强助手 (Manga Favorites Enhancer) v4

一个**站点无关**的油猴（Tampermonkey）用户脚本，包含两个独立的弹窗工具（同一个 📚 按钮，窗口内切换标签页）：

- **📚 收藏库**：给"收藏列表没有搜索 / 分类功能"的漫画平台做本地收藏管理——标签分类、关键字搜索、封面网格、自建标签、批量打标；
- **🧲 资源库**（v4 泛化）：嗅探**当前网页的一切资源**（图片 / 视频 / 音频 / 文档 / 压缩包 / 字体 / 其他），按类型分类浏览、预览（图片大图、视频/音频内嵌播放）、单个或批量下载。

窗口是 `window.open` 打开的**原生浏览器窗口**：可最小化、可拖到副屏、可和原页面并排。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. Tampermonkey 面板 → 「添加新脚本」→ 粘贴 `manga-fav-enhancer.user.js` 全部内容并保存。
3. 页面右下角出现 📚 按钮即安装成功；脚本不改动页面本身任何内容。
4. 首次使用「下载」时 Tampermonkey 可能询问跨域下载许可，允许即可（脚本声明了 `@connect *`）。

## 收藏库用法

1. 打开漫画站的**收藏 / 书架列表页**，点 📚 → 「收藏库」标签。
2. **扫描本页**抓取收藏卡片；**连续扫描**自动跟随"下一页"抓完所有分页（后台 fetch，不刷新页面）。
3. 左侧分类栏（全部 / 未分类 / 各标签带计数）+ 顶部搜索（多关键字空格分隔，匹配标题/作者/标签）+ 封面网格（点卡片打开详情页）。
4. 卡片悬停点 ✎ 单独打标；勾选多张后底部「打标签」批量归类——这是给没有标签体系的站点做分类的主要方式。
5. 「备份」导出/导入 JSON（含自建标签）。

## 资源库用法（v4）

1. 打开任何有资源的网页，点 📚 → 「资源库」标签 → **扫描本页资源**。
2. 脚本读取页面所有可获取的资源并去重分类：
   - `<img>`（含 `srcset` 懒加载、`<picture>`）、CSS `background-image`；
   - `<video>`（含 `<source>` 子标签、封面 poster）、`<audio>`；
   - `<embed>` / `<object>`；
   - `<a href>` 直接指向资源文件的链接；
3. **左侧分类栏**按类型筛选（图片/视频/音频/文档/压缩包/字体/其他，带计数）；
4. **搜索框**按文件名 / URL 过滤；**仅本站**开关排除第三方 CDN 噪音；
5. **预览**：点卡片——图片看大图，视频/音频直接内嵌播放；不支持内嵌的类型给出下载入口；
6. **下载**：卡片悬停点 ⬇ 单个下载；勾选多个后底部「⬇ 下载所选」批量下载（每 350ms 一个，防止浏览器拦截）；「复制 URL」批量复制链接；
7. 图片卡片会显示分辨率（从原页面读取 `naturalWidth/Height`）。

## 防误抓机制（收藏库）

- **内置站点预设**：命中预设的站点只用精确选择器。当前内置 `18comic / JM 系`：`div[id^="favorites_album_"]` + `.video-title` + `img.img-responsive` + `a[href*="album"]`。
- 通用启发式只对未命中预设的站点生效，且要求"详情链接 + 封面 + ≥4 个同构卡片"；可在设置里关闭。
- **设置 → 测试当前页**：先看"识别几个容器 / 解析成功几条"再入库。

## 数据与隐私

收藏数据存本地 `localStorage`（按站点主机名分库），资源嗅探结果只在弹窗内存里、不落盘；不上传任何服务器。

## 已知边界

- 「连续扫描」走 fetch，适用于普通 GET 分页；强 JS 渲染的站点请手动翻页 + 逐页扫描。
- 资源嗅探**看不到**页面运行时用 blob: / MSE 流加载的视频（如部分流媒体站），这类地址无法直接下载。
- CSS 背景图扫描上限 4000 个元素，超大页面可能漏扫（防卡顿）。
- 跨域下载依赖 GM_download；个别服务器禁外链时下载会由浏览器接管。
- 脚本只读页面内容、运行在用户浏览器内，不模拟登录、不绕过访问控制；请遵守各站点服务条款，下载资源仅限个人使用。
