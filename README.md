# 漫画收藏增强助手 (Manga Favorites Enhancer) v3

一个**站点无关**的油猴（Tampermonkey）用户脚本。给任何"收藏列表没有搜索 / 分类功能"的漫画平台提供**「收藏库」**：点页面右下角 📚 打开一个**独立的浏览器弹窗窗口**（原生窗口，可最小化、可拖到副屏、可和漫画页并排），内含左侧标签分类 + 关键字搜索 + 封面网格，支持自建标签归类、批量打标。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. Tampermonkey 面板 → 「添加新脚本」→ 粘贴 `manga-fav-enhancer.user.js` 全部内容并保存。
3. 页面右下角出现 📚 按钮即安装成功；脚本不改动页面本身任何内容。

## 使用

1. 打开漫画站的**收藏 / 书架列表页**，点右下角 📚 弹出独立的「收藏库」窗口。
2. **扫描本页**：抓取当前页的收藏卡片。**连续扫描**：自动跟随"下一页"抓完所有分页（在后台 fetch，不刷新页面）。
3. 之后随时可用收藏库：
   - **左侧分类栏**：全部 / 未分类 / 各标签（带计数），点标签即筛选；
   - **顶部搜索框**：多关键字空格分隔，匹配标题 / 作者 / 标签；
   - **封面网格**：直接浏览封面，点卡片新标签打开详情页；
   - **自建标签**：卡片悬停点 ✎ 编辑标签；或勾选多张卡片后点底部「打标签」批量归类——这是给没有标签体系的站点做分类的主要方式；
   - **删除**：批量勾选后删除本地记录（不影响网站收藏）。
4. 「备份」：导出 / 导入 JSON（含自建标签），可迁移到其他浏览器。
5. 弹窗窗口的位置和大小会被记住；Esc 或 ✕ 关闭。

> 提示：弹窗通过 `window.opener` 与原页面同源协作（扫描动作在原页面 DOM 上执行）。如果原页面被关闭或跳转到其他站点，弹窗里的扫描按钮会提示重新打开；已抓取的数据不受影响。若浏览器拦截弹窗，请允许本站弹出窗口。

## 防误抓机制（v2 重点）

- **内置站点预设**：命中预设的站点只用预设里的**精确选择器**，抓不到别的。当前内置：
  - `18comic / JM 系`：`div[id^="favorites_album_"]` + `.video-title`（标题）+ `img.img-responsive`（封面）+ `a[href*="album"]`（链接）
- **通用启发式默认只对未命中预设的站点生效**，且要求"详情链接 + 封面 + 至少 4 个同构卡片"才认定为列表。
- 不放心可以在 **设置 → 通用启发式探测** 直接关掉，关闭后该站只按精确选择器抓。
- **设置 → 测试当前页**：当场显示"识别几个容器 / 解析成功几条 / 首条内容"，确认没抓错再入库。

## 数据与隐私

全部数据存在本地 `localStorage`（按站点主机名分库），不上传任何服务器；清浏览器数据前记得导出备份。

## 已知边界

- 「连续扫描」走 fetch，适用于普通 GET 分页；强 JS 渲染或 POST 翻页的站点请手动翻页 + 逐页扫描。
- 封面图引用原站 URL，同站页面内展示无防盗链问题；JSON 备份不含图片本体。
- 脚本只读页面内容、运行在用户浏览器内，不模拟登录、不绕过访问控制；请遵守各站点服务条款。
